 🚌 DTC Bus Scheduling and Route Management System

A full-stack web application for automating duty scheduling and route management for Delhi Transport Corporation (DTC). Built using React, Tailwind CSS, Node.js, Express, and MongoDB.

## 📁 Folders

- `client/` - Frontend using React + Tailwind
- `server/` - Backend using Node.js + Express
- `docs/` - Project docs, wireframes, diagrams

## 🚀 Features
- Role-based login (Admin, Scheduler, Depot Manager)
- Linked/unlinked duty scheduling
- GIS-based route drawing
- Crew/bus management dashboard
